## 0. 비교 방법론

round1 원본 지표는 옛 채점기(`document_retrieval`/`structured_lookup` 분리 전, 검증기
삭제를 Retriever 실패로 세던 버전)로 계산됐다. round2(현재 채점기)와 직접 비교하면
"Agent 동작이 좋아진 효과"와 "채점 기준이 바뀐 효과"가 섞인다.

그래서 **round1 의 원시 실행 결과(120건, Tool trace·답변·출처는 그대로)를 현재 채점기로
다시 채점**해 대조군(`baseline_dev_metrics_round1_regraded.json`)을 만들고, 이것과
round2 를 같은 기준으로 비교했다. 아래 모든 표는 "재채점된 round1" 대비 round2 다.

### Validator·Generation 항목은 대부분 정탐

`Validator: 답변 삭제(재확인 필요)` 2건(`report-09`, `mix-09`)을 직접 확인했다.

## 6. 뉴스 비현행 청크 941건과 검색 실패의 실제 연결

**확인 결과: 뉴스 Retriever 실패 15건 중 14건(93%)이 비현행 중복 문서와 실제로 연결됨.**

방법: 실패한 각 문항의 정답 사건(`news_clusters.id`)에 대해 `rag_documents` 를
조회해 문서 개수와 `is_current=false` 존재 여부를 확인했다(정리·재색인은 하지 않음).

| 사건 예시 | 문서 수 | 비현행 존재 |
|---|---:|---|
| news-02 (현대차 아세안 현대컵) | 12 | 예 |
| news-03 (삼성전자 갤럭시Z 폴드8) | 3 | 예 |
| news-06 | 7 | 예 |
| news-08 | 4 | 예 |
| news-04 (두산에너빌리티 원전 수주) | 1 | **아니오** |

**예외 1건(`news-04`)은 색인 중복이 아니라 다른 원인**이다 — Agent 가
`relative_period='recent'`(최근 2일)로 좁혀 검색했는데 실제 사건이 그보다 오래돼
의미 검색 자체가 놓쳤다. 이건 진짜 검색 품질 문제로 남긴다.

**결론**: 뉴스 검색 실패의 대다수(93%)는 색인 정합성 문제이지 Retriever 알고리즘
자체의 결함이 아니다. 재색인·중복 정리가 이번 범위 밖이라 손대지 않았지만, 다음
라운드의 최우선 후보로 확정됐다.

## 7. 가장 큰 남은 문제 5개

1. **뉴스 색인 중복** — 실패 14/15건이 이 문제. 비현행 문서의 활성 청크가 검색 대상에
   남아 정답이 아닌 문서를 반환한다. (계층: 데이터·색인 정합성)
2. **Agent Tool 선택 오류** — 13건(필수 누락 6·불필요 호출 6·금지 호출 1). 대부분
   복합 질문·공시 문항에서 발생. (계층: Agent Tool 선택)
3. **평가기·라벨 잔여 문제** — 16건. 대부분 §5 에서 확인한 정탐(검증기가 실제
   환각을 잡은 것)인데 "미확정 검색 실패" 분류에 남아 다음 라벨 정리가 필요.
   (계층: 평가기·라벨)
4. **Tool 인자 해석 오류** — 7건. 남은 것은 대부분 세부 계정명·기간 표현의 미세
   불일치로, 1차 교정에서 다룬 유형(enum·단독/별도)과는 다른 잔여분. (계층: Tool 인자)
5. **리포트 Retriever 정답 미검색 2건** — 규모는 작지만 리포트 검색 품질 확인 필요.
   (계층: 리포트 Retriever)

## 8. 다음에 수정할 최소 범위 (제안, 미실행)

우선순위:

1. **뉴스 재색인/중복 정리** — 이번 확인으로 최우선 근거가 확정됐다(93% 연결).
   `is_current=false` 문서의 청크를 `is_active=false` 로 정리하는 데이터 작업.
2. **Agent Tool 선택 프롬프트 보강** — 복합 질문에서 불필요/누락 호출이 반복되는
   패턴을 구체 사례로 조사 후 최소 수정.
3. **평가기·라벨 2차 정리** — §5 에서 확인한 정탐 사례들이 "미확정"으로 남지 않도록
   라벨 근거를 보강(점수 목적 변경 아님).

이번 작업에서는 어느 것도 실행하지 않았다.

## 9. 홀드아웃 실행 가능 여부

**아직 이르다.**

- 치명적 오류가 54 → 12(고유 10)로 크게 줄었으나 0은 아니다.
- 뉴스 검색 실패의 근본 원인(색인 중복)이 확정됐지만 아직 수정 전이다.
- 다음 라운드(뉴스 재색인)를 거쳐 문서 검색 지표가 정상 범위로 올라온 뒤
  홀드아웃을 쓰는 것이 순서에 맞다.
