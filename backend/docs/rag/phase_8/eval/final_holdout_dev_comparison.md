개발셋의 97.44%는 외부 장애 3건을 제외한 수치다. 홀드아웃의 85.00%와
섞어 표현하지 않는다.

홀드아웃에서는 Tool 선택과 인자 형식은 높았지만 실제 Tool 실행 성공이
일반화되지 않았다. 31문항에서 Tool 오류 또는 `step_limit`이 관찰됐고,
32문항은 최종 출처가 없었다. 따라서 통과율 차이를 단순한 답변 모델 과적합으로만
해석할 수 없으며, 실행 시점의 제품 Tool 경로 실패가 지배적인 요인이다.

동결 채점기의 복합 완료율은 “필수 Tool 이름을 호출했는가”를 측정하므로
`h-mix-20`의 빈 답변·`step_limit`도 100% 지표에 반영되지 않는다. 실제 최종
답변 기준 복합 완료는 4/5(80%)다.

뉴스 event-equivalent Hit@1/MRR은 개발셋 기존 산출물에 저장되지 않아 비교값을
만들지 않았다. 홀드아웃은 승인된 추가 cluster가 없고 전부 검색 실패해
Recall@K·Hit@1·MRR이 모두 0이다.
