이 표는 모두 기존 Phase 8 홀드아웃 40문항을 재사용한 회귀 결과다. 신규 홀드아웃이나
일반화 성능이 아니며, targeted API 결과와 합산하지 않는다.

이번 formal 하락은 `h-fin-23`, `h-news-23`, `h-news-24` 세 문항이다.

- `h-fin-23`: 제품의 일반 규칙은 기간만 적힌 “3분기”를 해당 분기 3개월치로 해석한다.
  그러나 이 Gold는 누적으로 라벨링되어 있다. 같은 표현의 `h-fin-20` Gold는 반대로
  3개월치다. 종목이나 계정별 하드코딩 없이는 두 Gold를 동시에 만족할 수 없다.
- `h-news-23`: 인물 역할 제거 안전장치가 있어도 semantic classifier가
  `이재명 대통령`을 역할 없는 별도 회사로 축약해 다중 종목으로 차단했다. 제품 결함이다.
- `h-news-24`: 현대차 화면에서 기아를 명시한 실제 다중 회사 질문이다. 새 안전 정책은
  타 회사 데이터 혼입 방지를 위해 Tool 실행 전에 차단하지만 기존 Gold는 검색을 요구한다.
  정책과 Gold의 명시적 충돌이다.

뉴스 Recall은 2/6에서 3/6으로 개선됐지만, 위 두 안전 차단 때문에 제품 뉴스 실패는
2/6이다. 리포트 검색 순위는 5/5 Hit@1까지 개선됐다. 반면 리포트 page accuracy는
Phase 10의 4/14에서 0/14로 하락했다. 결과 locator에는 `page_number` 또는
`target_price_source_page`가 있지만 top-level `page`가 null인 직렬화 계약 결함이다.
