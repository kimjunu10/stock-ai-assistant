# 초보자용 재무 요약·컨센서스 적용 조사

- 조사일: 2026-07-25
- 대상: 네이버 증권 종목분석의 Financial Summary, 투자의견 컨센서스
- 범위: 데이터 취득 가능성, 라이선스 위험, 현재 RAG/종목 UI 적용 가능성
- 상태: 조사만 완료, 구현·DB 변경 없음

## 1. 결론

네이버 종목분석 화면과 같은 정보 구조는 만들 수 있다. 다만 네이버/WiseReport HTML이나
내부 AJAX를 운영 수집기로 직접 스크래핑하여 저장하는 방식은 채택하지 않는다.

권장 경로는 다음 두 단계다.

1. 무료·공식 데이터 우선:
   - OpenDART 확정 재무값과 주요 재무지표
   - 현재 Toss API의 실제 주가
   - 현재 적재된 증권사 리포트의 구조화 목표주가·투자의견
2. 시장 전체 컨센서스와 추정실적이 반드시 필요할 때:
   - FnGuide의 정식 API/데이터 계약 및 외부 고객 노출 권한을 별도 협의

## 2. 네이버 화면의 실제 데이터 구성

확인한 네이버 종목 페이지:

- <https://finance.naver.com/item/coinfo.naver?code=005930>
- 내부 종목분석 화면:
  <https://navercomp.wisereport.co.kr/v2/company/c1010001.aspx?cmp_cd=005930>

페이지는 네이버 자체 산출 데이터가 아니라 FnGuide 제공 기업·재무정보를 포함한다.

### Financial Summary

다음 범주가 함께 표시된다.

- 확정 실적(A): 매출액, 영업이익, 당기순이익, 자산·부채·자본, 현금흐름
- 파생 재무지표: 영업이익률, 순이익률, ROE, ROA, 부채비율
- 주당·밸류에이션 지표: EPS, BPS, PER, PBR
- 현금흐름 파생값: CAPEX, FCF
- 전망치(E): 연간·분기 매출, 이익, EPS 등 증권사 추정 평균

페이지 설명상 `(A)`는 실적, `(E)`는 컨센서스이며, 컨센서스는 최근 3개월 증권사
추정치 평균이다. 분기 지표 일부는 직전 4개 분기를 연환산한다.

### 투자의견 컨센서스

기준일과 함께 다음을 제공한다.

- 1~5 투자의견 점수
- 평균 목표주가
- 추정 EPS/PER
- 추정기관 수
- 증권사별 최신 목표가·직전 목표가·변동률·투자의견
- 목표주가/현재가 추이와 투자의견 분포

## 3. 직접 수집 가능성과 위험

### 기술적 가능성

Financial Summary는 화면 로드 후 `company/ajax/cF1001.aspx`가 HTML 조각을 반환한다.
호출에는 종목코드, 재무제표 구분, 연간/분기 구분과 페이지에서 생성된 `encparam`이
필요하다. 투자의견 컨센서스와 증권사별 표는 메인 HTML에도 포함된다.

따라서 기술적으로 파싱은 가능하지만 다음 이유로 운영 데이터 소스로 부적합하다.

- 비공식 내부 화면 계약으로 필드·토큰·DOM이 예고 없이 바뀔 수 있음
- 기준일과 업데이트 지연을 우리가 통제할 수 없음
- 원천 데이터가 FnGuide 저작물임
- 네이버 페이지는 게시 정보의 무단 배포를 금지함
- FnGuide 화면은 사전 허가 없는 사용·DB화를 금지한다고 명시함

### 정식 FnGuide 경로

FnGuide는 DataGuide와 FnSpace API에서 재무·컨센서스 데이터를 유료 제공한다.
다만 FnSpace 공개 안내의 일반 사용권은 데이터와 가공 데이터를 애플리케이션에 포함해
고객에게 노출하는 것을 제한한다. 우리 웹 서비스에 표시하려면 단순 API 구독이 아니라
외부 서비스 노출·재배포가 포함된 별도 상업 계약 여부를 FnGuide에 확인해야 한다.

참고:

- [FnGuide DataGuide 서비스 소개](https://help-dataguide.fnguide.com/ko/articles/DataGuide-%EC%84%9C%EB%B9%84%EC%8A%A4-%EC%86%8C%EA%B0%9C-24a3434a)
- [FnGuide DataGuide 이용·요금 안내](https://help-dataguide.fnguide.com/ko/articles/%EC%9D%B4%EC%9A%A9-%EB%B0%8F-%EC%9A%94%EA%B8%88-%EC%95%88%EB%82%B4-48b18a4b)
- [FnGuide FnSpace API 소개·라이선스](https://fnspace3.fnguide.com/Customer/Info)
- [FnGuide Consensus 안내](https://www.fnguide.com/download/CONSENSUS_USER_GUIDE.pdf)

## 4. 현재 우리 데이터로 가능한 범위

### 4.1 공식 확정 재무 요약 — 바로 확장 가능

현재 구현:

- 종목 화면 `/financial-summary`
- 최신 DART 보고기간의 매출액·영업이익·당기순이익
- 전년 동기 대비 변화
- RAG `get_financial_facts`

현재 DB의 재무 계정:

- 매출액, 영업이익, 당기순이익
- 자산총계, 부채총계, 자본총계
- 영업·투자·재무활동 현금흐름

OpenDART 공식 `fnlttSinglIndx` API를 추가 사용하면 2023년 3분기 이후 보고서에 대해
다음 네 범주의 지표를 받을 수 있다.

- 수익성: 순이익률, ROE, 총자산영업이익률 등
- 안정성: 부채비율, 유동비율, 자기자본비율 등
- 성장성: 매출액·영업이익·순이익 증가율 등
- 활동성: 총자산·재고자산 회전율 등

2026년 삼성전자 1분기를 실제 호출해 순이익률, ROE, 부채비율, 유동비율,
매출액/영업이익/순이익 증가율 등의 값이 반환되는 것을 확인했다.

공식 문서:

- [OpenDART Open API 소개](https://opendart.fss.or.kr/intro/main.do)
- [단일회사 주요 재무지표 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2022001)

주의:

- PER/PBR/EPS/BPS는 주가·수정주식수·지배주주 기준 등 산식이 섞인다.
- LLM이나 프런트에서 임의 계산하지 않는다.
- OpenDART가 직접 주는 공식 재무비율과 실제 주가를 우선 사용하고, 밸류에이션은
  정의와 데이터 라이선스가 확정된 별도 provider가 있을 때 추가한다.

### 4.2 자체 리포트 요약 — 제한적으로 가능

현재 `research_reports`에는 종목별 리포트의 다음 구조화 필드가 있다.

- 증권사, 발행일, 투자의견
- 검증된 목표주가와 상태
- 근거 페이지와 리포트 본문/표

2026-07-25 기준 최근 90일 적재 상태:

| 종목 | 리포트 | 증권사별 최신 목표주가 표본 | 최신 발행일 |
|---|---:|---:|---|
| SK하이닉스 | 21 | 10 | 2026-07-14 |
| 현대차 | 5 | 4 | 2026-07-10 |
| 삼성전자 | 37 | 12 | 2026-07-08 |
| 두산에너빌리티 | 9 | 9 | 2026-05-04 |
| 한화오션 | 12 | 8 | 2026-07-15 |

삼성전자는 증권사별 최신 12개 목표주가로 평균 470,000원, 중앙값 480,000원,
범위 300,000~580,000원을 계산할 수 있었다. 같은 날 FnGuide 화면은 24개 기관,
평균 513,958원을 표시한다. 표본과 최신성이 다르므로 우리 값을 `시장 컨센서스` 또는
`네이버 컨센서스`라고 부르면 안 된다.

안전한 명칭:

- `Moa가 확인한 최근 리포트`
- `수집 리포트 목표주가 요약`
- `최근 90일 · 증권사별 최신 1건 · 표본 N곳`

필수 표시:

- 기준일, 조회 기간, 표본 증권사 수
- 평균뿐 아니라 중앙값과 범위
- 마지막 리포트 발행일
- 전망값이며 실제 주가·확정 실적이 아니라는 문구
- 표본 부족/90일 초과 여부

리포트 원문의 공개·상용 이용 범위는 구현 전 별도 확인이 필요하다. 현재 Phase 5
문서에도 공개·상용 출시 전 저작권 확인이 필요하다고 기록돼 있다.

### 4.3 추정실적 컨센서스 — 현재는 부족

FnGuide식 2026(E) 매출·영업이익·EPS 등을 만들려면 증권사별 추정치를 다음 키로
정규화해야 한다.

```text
stock_code
broker
report_date
forecast_period
account
value
unit
fs_div
source_report_id
source_page
```

현재 `research_report_tables`는 표 원문과 `actual/forecast/mixed` 구분은 보유하지만
종목·기간·계정·단위별 수치가 위 구조로 정규화돼 있지 않다. 따라서 지금 바로 평균을
내면 기간·단위·연결/별도·실적/전망 혼합 위험이 있다.

가능한 선택:

1. 정식 FnGuide API/재배포 계약
2. 사용 권리가 확인된 리포트만 대상으로 `report_estimates` 정규화 파이프라인 구축

## 5. 초보자용 종목 UI 권장안

네이버 표 전체를 복제하지 않고, 첫 화면에는 판단에 필요한 6~8개만 보여준다.

### A. 회사가 돈을 잘 버는가

- 최근 매출·영업이익·순이익
- 전년 동기 대비 증감
- 영업이익률 또는 순이익률

초보자 설명 예:

```text
매출은 회사가 번 전체 돈, 영업이익은 본업으로 남긴 돈이에요.
```

### B. 재무가 안전한가

- 부채비율
- 유동비율 또는 자기자본비율
- 위험/양호 단정 대신 업종 비교가 없으면 수치와 정의만 표시

### C. 시장은 어떻게 보고 있는가

- 수집 리포트 표본 수
- 목표주가 중앙값
- 목표주가 범위
- 매수/중립/매도 분포
- 실제 현재가와 전망값을 시각적으로 분리

### D. 더 보기

- 연간/분기 실제 실적 표
- 현금흐름, ROE, 성장률
- 증권사별 최신 리포트
- 각 카드의 `AI에게 물어보기`

첫 화면에서 PER·PBR·CAPEX·FCF를 모두 나열하지 않는다. 용어를 모르는 사용자는
카드를 누르면 정의와 “높고 낮음이 무엇을 뜻하는지”를 RAG가 설명하게 한다.

## 6. Agentic RAG 적용 구조

키워드 라우터나 질문별 하드코딩 없이 typed Tool을 추가한다.

```text
get_financial_snapshot
  → DART 확정 실적 + OpenDART 공식 재무지표

get_report_consensus_summary
  → 수집 리포트에서 증권사별 최신 1건
  → 평균/중앙값/범위/분포/표본 수를 백엔드가 계산

search_research_reports
  → 특정 증권사 의견과 전망 근거 검색
```

원칙:

- Agent가 질문 의미에 따라 필요한 Tool을 선택한다.
- 평균·중앙값·비율은 LLM이 계산하지 않고 Tool이 반환한다.
- `actual_value`, `official_ratio`, `forecast_value`를 분리한다.
- 모든 요약에 `as_of_date`, `coverage_count`, `window_days`, `source_ids`를 포함한다.
- UI와 RAG가 같은 Snapshot Service를 사용해 화면과 답변 숫자가 달라지지 않게 한다.

## 7. 권장 구현 순서

### 1순위 — 공식 재무 핵심지표

- OpenDART `fnlttSinglIndx` 수집
- `financial_indicators` 테이블
- `get_financial_snapshot` Tool
- 종목 화면 `한눈에 보는 재무` 카드

비용과 법적 위험이 낮고 초보자 가치가 가장 크다.

### 2순위 — 자체 리포트 요약

- 증권사명 정규화
- 최근 90일, 증권사별 최신 1건 집계
- 목표주가 중앙값·범위·분포
- `시장 전체 컨센서스가 아님` 라벨
- 종목 UI와 RAG 공용 typed response

### 3순위 — 정식 컨센서스

- FnGuide에 외부 웹서비스 노출·재배포 조건 문의
- 계약 가능하면 공식 API provider 추가
- 실제값(A)/전망값(E) 별도 저장 및 UI 배지

### 보류

- 네이버/WiseReport HTML·내부 AJAX 운영 스크래핑
- 리포트 표를 정규화하지 않고 LLM으로 평균 계산
- 산식·기준이 다른 PER/PBR/EPS를 임의 조합
- 표본 수를 숨긴 채 자체 집계를 `시장 컨센서스`로 표시
