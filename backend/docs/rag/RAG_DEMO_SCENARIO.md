# RAG 시연 시나리오

이 시연은 답변 문구나 목차를 고정하지 않는다. 질문에 필요한 조회 도구와 출처, 기간,
수치의 의미가 맞는지만 검증한다.

## 촬영 전 점검

최신 `main` 기준 프론트엔드와 백엔드를 실행한 뒤 아래 명령을 실행한다.

```bash
cd backend
.venv/bin/python scripts/verify_rag_demo.py --base-url http://127.0.0.1:8765 --repeat 2
```

가격 공급자 장애가 확인된 상태에서 나머지 시나리오만 점검하려면 `--skip-price`를 붙인다.
다만 실제 촬영에는 가격 질문을 넣지 않거나, 가격 공급자가 복구된 뒤 전체 점검이 통과해야
한다.

## 권장 촬영 흐름

종목은 삼성전자 한 종목으로 미리 선택한다.

1. `삼성전자 요즘 실적 좋아지고 있어?`
   - 최신 공시의 동일 분기끼리 전년 동기 비교하는지 보여준다.
   - 1분기와 3분기처럼 서로 다른 누적 기간을 비교하면 실패다.
2. `삼성전자 2분기 실적 알려줘`
   - 사용자가 연도를 생략해도 서버 현재 연도인 2026년을 조회한다.
   - 아직 공시가 없으면 없다고 답해야 하며, 2025년 자료로 몰래 대체하면 실패다.
3. `삼성전자 올해 배당 얼마 줘?`
   - 일상적인 표현의 “배당 얼마”를 주당 현금배당금으로 해석한다.
   - 주당순이익(EPS)이나 배당 총액을 주당 배당금처럼 답하면 실패다.
4. `오늘 삼성전자 뭐 악재 있었어?`
   - 감성 분류가 저장된 뉴스 사건을 사용하고, 해당 회사와 직접 관련된 출처를 우선한다.
   - 뉴스와 주가의 직접 인과는 단정하지 않는다.
5. `오늘 삼성전자 주가 왜 내렸어? 뭐 악재 있었어?`
   - 가격 도구의 실제 등락률과 뉴스 도구의 관련 배경을 함께 사용한다.
   - 뉴스 제목의 등락률을 현재 주가 등락률로 재사용하면 실패다.
   - 외부 가격 공급자가 실패하면 수치를 추측하지 않고 조회 실패를 명시해야 한다.

## 촬영 선택

안정적인 본편은 1 → 3 → 4 순서가 좋다. 가격 공급자 상태까지 전체 점검이 통과하면
5를 첫 장면에 넣어 사용자가 가장 자주 묻는 “오늘 왜 내렸지?” 흐름을 보여준다.
